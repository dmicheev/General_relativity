## 2. Визуальная полировка

### 2.1. Светящийся луч

**Задача:** луч должен читаться как свет, а не как серая линия.

**Подход без постобработки** (надёжнее и дешевле):

1. Геометрия — camera-facing ribbon (полоса из квадов), ширина ≈ 0.03 м.
2. WGSL-материал с UV, где `v ∈ [0,1]` поперёк полосы.
3. Функция яркости:
   ```
   d = abs(v - 0.5) * 2.0
   core = exp(-d * d * 12.0)
   halo = exp(-d * d * 2.0) * 0.25
   alpha = core + halo
   ```
4. Блендинг: **additive** (`BlendState::ALPHA_BLENDING` или кастомный additive).
5. `depth_write = false`, `depth_test = less`.
6. Три слоя ribbon сDifferent шириной — опционально, для мягкого glow.

**Почему не bloom-pass:** для одного луча полноценный post-processing
bloom — избыточная сложность и стоимость. Ribbon решает задачу за один draw call.

### 2.2. Материал пружины

Исправить артефакт масштабирования проволоки с T03.

**Подход:** vertex shader с uniform `compression`:

```
// исходная геометрия: helix единичной высоты
// сжимаем только продольную координату, не толщину проволоки
position.y *= (1.0 - 0.65 * compression);
```

Для этого геометрия должна храниться в **несжатом** виде,
а сжатие применяться в шейдере, а не через `Transform::scale`.

Нормали пересчитывать приближённо или использовать
`normalize(normalMatrix * normal)` — для малого сжатия ошибка незаметна.

### 2.3. Кабина

- Пол:Grid-текстура с метровой шкалой (1 м клетки) — даёт ощущение масштаба.
- Стены: полупрозрачные, `alpha = 0.12`, с видимыми рёбрами.
- Потолок: только рёбра.
- Эмиттер: небольшой цилиндр + кольцевая метка.
- Точка попадания: кольцо + короткий текстовый label.

### 2.4. Что сознательно НЕ делаем

> **Гравитационное линзирование через post-processing shader — вне объёма.**

Радиальный distortion экрана выглядит эффектно, но **физически не соответствует
принципу эквивалентности в однородном поле**. Добавить его — значит научить
пользователя неправильной причинности.

Если такой модуль понадобится — это отдельный проект про чёрные дыры
и геодезические в Шварцшильде.

## 3. Релизный пайплайн

### 3.1. Сборка

```bash
trunk build --release
wasm-opt -O3 --strip-debug --strip-producers \
  -o dist/einstein-lift.wasm dist/einstein-lift.wasm
```

Проверить, что Trunk не применяет `wasm-opt` повторно.

### 3.2. Обязательные HTTP-заголовки

```
Content-Type: application/wasm
Cache-Control: public, max-age=31536000, immutable
```

> **`Content-Type: application/wasm` критичен.**
> При `application/octet-stream` браузер может отключить streaming compilation,
> что заметно увеличивает время первой загрузки.

### 3.3. Сжатие

Подготовить **заранее**:

- `einstein-lift.wasm.br` (brotli, quality 11)
- `einstein-lift.wasm.gz` (gzip, −9)

Statichosting должен отдавать правильный `Content-Encoding`.
Проверить, что сервер не сжимает уже сжатый `.br`.

### 3.4. Multithreading

**Не включён.** Следовательно COOP/COEP **не нужны**.
Это позволяет деплоить на любой static hosting без специальной настройки.

### 3.5. Fallback для неподдерживаемых браузеров

При отсутствии WebGPU / WebGL2:

```text
Ваш браузер не поддерживает требуемую графическую API.

Рабочие варианты:
  • Firefox / Chrome / Edge последней версии
  • Safari 18+ на macOS / iOS

Подробности: [ссылка на caniuse WebGPU]

Сам текст принципа эквивалентности доступен ниже —
приложение не единственный способ изучения.
```

**Требование:** текстовое объяснение принципа эквивалентности
должно быть доступно **без WebGL вообще**. Это и доступность, и SEO.

## 4. CI

### 4.1. Этапы

```yaml
# концептуальная схема
1. cargo fmt --check
2. cargo clippy -- -D warnings
3. cargo test -p lift-core                      # нативно, быстро
4. rustup target add wasm32-unknown-unknown
5. cargo build --release --target wasm32-unknown-unknown
6. trunk build --release
7. проверить размер артефакта против бюджета
8. загрузить dist/ как CI artifact
9. (на push to main) деплой на Pages
```

### 4.2. Размерный бюджет в CI

```bash
SIZE=$(gzip -c dist/*.wasm | wc -c)
if [ "$SIZE" -gt 8388608 ]; then
  echo "WASM gzip size $SIZE exceeds 8 MiB budget"
  exit 1
fi
```

Бюджет — **предупреждающий**, его можно пересматривать через PR
с объяснением, какая фича его изменила.

### 4.3. Регрессионные физические тесты

CI **обязан** запускать:

```text
T01.*  FrameParams / g_eff
T02.*  эквивалентность Planet ↔ Rocket
T04.*  прямая в FreeFall / парабола в Rocket
T04.9  парабола vs Риндлер
```

Эти тесты не требуют браузера и должны падать при любой регрессии физики.
