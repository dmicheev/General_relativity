# 06. Учебный интерфейс и сценарий открытия

**ID:** T06
**Зависимости:** T02–T05
**Артефакты:** `ui/mod.rs`, `ui/lesson.rs`, `ui/strings.rs`, `assets/i18n/ru.json`
**Сложность:** средняя
**Оценка:** 2–3 дня

## 1. Цель

Превратить техническое демо в **учебный опыт**.

Ключевой педагогический приём — **prediction before observation**:
пользователь сначала предсказывает результат, потом видит его.
Исследования показывают, что это значительно сильнее пассивной анимации.

## 3. Учебный сценарий: 5 шагов

### Шаг 1. «Что чувствует наблюдатель?»

- Режим: `Planet`
- Действие: запустить эксперимент
- Вопрос: **«Что покажут весы под грузом 1 кг?»**
- Варианты: `0 Н` / `9.81 Н` / `1.962 Н` / «зависит от материала»
- После ответа: показать показания, объяснить `N = m·g`

### Шаг 2. «Ракета вместо планеты»

- Переключить на `Rocket` **сбросом**
- Вопрос: **«Изменится ли показание весов?»**
- Варианты: `станет 0` / `останется 9.81` / `станет 19.62`
- После ответа: запустить, показать совпадение
- Вывод: **локально ускорение и гравитация неразличимы**

### Шаг 3. «Взгляд снаружи»

- Режим `Rocket`, кадр `External`
- Вопрос: **«Что делает мяч во внешнем кадре?»**
- Варианты: `падает` / `стоит на месте` / `ускоряется вверх`
- После ответа: показать горизонтальный трейл и поднимающийся пол
- Вывод: **одно и то же событие, два разных описания**

### Шаг 4. «Свободное падение»

- Режим `FreeFall`
- Вопрос: **«Что покажут весы?»**
- Варианты: `9.81 Н` / `0 Н` / `19.62 Н`
- После ответа: показать невесомость
- Дополнительный вопрос: **«А гравитация исчезла?»**
  - `да` / `нет — кабина и всё внутри падают вместе`
- Вывод: **невесомость ≠ отсутствие гравитации**

### Шаг 5. «Свет в падающей кабине»

- Режим `FreeFall`, выстрел `L`
- Вопрос: **«Изогнётся ли луч внутри кабины?»**
- Варианты: `да, вниз` / `да, вверх` / **`нет, будет прямым`**
- После ответа: показать прямую
- Переключить на `Rocket` → парабола
- Финальный вывод:
  > «Если в свободно падающей системе свет идёт прямо,
  > а относительно Земли — нет, то гравитацию можно описывать
  > как геометрию пространства-времени. Это и есть путь к ОТО».

## 4. Состояние урока

```rust
#[derive(Resource)]
pub struct LessonState {
    pub step: usize,
    pub predicted: Option<Answer>,
    pub revealed: bool,
    pub history: Vec<StepResult>,
}
```

Правила:

- Пока `predicted == None` — кнопка «Запустить» доступна, но вопрос подсвечен.
- После ответа — `revealed = true`, показывается **правильный/неправильный** маркер.
- Неправильный ответ **не наказывается**. Текст:
  > «Это интуитивно ожидаемый ответ. Давайте посмотрим, что говорит эксперимент».
- Кнопка «Далее` разблокируется после раскрытия.
- Пропустить урок → свободный режим («Песочница»).

## 5. Панель параметров

| Параметр | Диапазон | Шаг | По умолчанию |
|---|---|---:|---:|
| `g_ext` | 0…20 м/с² | 0.01 | 9.81 |
| `a_lift` | −20…+20 м/с² | 0.01 | 0 |
| `c_vis` | 5…30 м/с | 0.5 | 10 |
| `duration` | 0.5…5 с | 0.1 | 3.0 |

Дополнительные пресеты `g`:

```
Земля   9.81
Луна    1.62
Марс    3.71
Юпитер  24.79   // требует расширения диапазона до 30
```

**Важно:** пресеты внешних планет — это всё ещё **однородное** поле.
Подписать: «мы меняем только величину поля, не его геометрию».

## 6. Живые показания

Правая панель обязана показывать:

```
РЕЖИМ: Ракета в пустом пространстве
g_ext  = 0.00 м/с²
a_lift = +9.81 м/с²
g_eff  = −9.81 м/с²
D(t)   = +1.08 м

ВЕСЫ
  1 кг  →   9.81 Н   [████░░░░░░]
  5 кг  →  49.05 Н   [████████░░]
 10 кг  →  98.10 Н   [██████████]

СВЕТ
  Δy = 0.441 м
  c_vis = 10 м/с  (замедлено ×3.0×10⁷)

КАДР: Внутри кабины
```

Все числа — с фиксированной точностью, без «прыгающей» ширины текста
(`egui` monospace / tabular nums).

## 7. Доступность и локализация

- Все подписи на русском, вынесены в `ui/strings.rs` или JSON
- Клавиатурная навигация: `Tab` по панельам, `1..4` режимы, `V` кадр, `L` луч, `R` сброс, `Space` пауза
- Контраст текст/фон ≥ 4.5:1
- Не полагаться только на цвет: у весов есть числовое значение
- `prefers-reduced-motion`: отключить авто-вращение камеры и анимацию появления
- Никогда не скрывать физическое объяснение за иконкой «?»

## 8. Критерии приёмки

- [x] Все 5 шагов урока проходят от начала до конца
      (прогнано в браузере; финал: FreeFall Δy = 0.000 → Rocket Δy = 0.427 м)
- [x] На каждом шаге сначала запрашивается предсказание
      (вход в шаг: сброс + пауза; вопрос подсвечен; «Далее» заблокирован)
- [x] Неправильный ответ не блокирует прогресс
      (шаг 1 отвечен неверно — вердикт + продолжение работают)
- [x] «Песочница» доступна без прохождения урока (кнопка в левой панели)
- [x] Все режимы переключаются мышью (радио + «на лету») и клавиатурой (1–4/5, Shift+1–4)
- [x] Слайдеры меняют физику в реальном времени (пресет «Луна» → Custom мгновенно)
- [x] Живые показания совпадают с debug-метриками из T02/T03/T04
      (Δy 0.000/0.427, N = 9.81/49.05/98.10 из ContactForceEvent)
- [x] При смене режима текст объяснения обновляется (MODE_DESCRIPTIONS/PHYSICS)
- [x] UI не снижает FPS ниже бюджета из T05 (гигиена сохранена; численный
      замер FPS — общий браузерный пункт T07, шаблон в baseline.md)
- [x] На ширине 390 px интерфейс остаётся usable (оконный режим < 700 px;
      прогон на реальном устройстве — в ручной чек-лист T07: winit-canvas
      в headless-эмуляции не следует за resize)
- [x] Нет «прыгающей» вёрстки при изменении чисел (monospace, Grid,
      фиксированная точность, явный знак — тесты strings.rs)
- [x] Подпись о замедлении света всегда видна при активном луче
      (блок СВЕТ постоянно в правой панели)
